# LESSON BRIEF 7.4 — Practical classification and resolving classification disputes

Course 3: Classification, Valuation, Origin and Duty · difficulty `intermediate`
Module 7: Harmonised System Classification · lesson 4 of 4 · module 7 of 15
Proposed slug: `practical-classification-and-resolving-classification-disputes`

## Summary

Classification disputes happen when the trader and the officer read the same goods
differently. The resolution path runs from a better product description, through the
notes and rules, to the objection and advance-ruling machinery the Act provides. This
lesson works real classification problems from the supplied tariff — goods a Ghanaian
trader actually clears — and teaches how a disagreement gets resolved lawfully.

## Learning Objectives

Work a classification from a product description to a TSN using the workbook's tables, showing each rule step.
Identify the two classic dispute drivers: ambiguous descriptions and competing headings.
State the trader's remedies — the advance ruling (s.12) and the objection (s.13) — and what each is for.
Explain how the 2017-base/2024-refresh difference shows up in practice, using the workbook against the TARIFF-24 caveat.

## Key Terms

identical goods :: goods, which are the same in all respects, including physical characteristics, quality, and reputation, but disregarding minor differences in appearance
similar goods :: goods which, although not alike in all respects, have like characteristics and like component materials which enable them to perform the same functions and to be commercially interchangeable
tariff :: the Tariff Schedule of Ghana
customs advance ruling :: a binding written statement issued by customs that interprets and applies customs laws and regulations to a specific set of facts upon application by a trade about a prospective transaction

## Source anchors

- `ACT` s.151 — the Key Terms above, verbatim from the Interpretation section
  ("identical goods" and "similar goods" are the valuation-side definitions; cite them
  where the classification of like goods is discussed).
- `ACT` ss.12–13 — advance ruling and objection, as the dispute remedies.
- `TARIFF` — the workbook: worked examples must cite the table, heading and TSN they
  walk through.
- `TARIFF-24` — `output/docx/HS CODE 2024 2.pdf` is a scan with no usable text layer;
  it is read visually or treated as unavailable, and the draft says which it did
  (spec C3).

**Fact-check caution.** Every worked classification must be re-verifiable: cite the
workbook row. Do not present a classification outcome as "correct" beyond the
supplied schedule, and carry the tariff-edition labelling rule (spec C4.2) into every
figure.
