# LESSON BRIEF 8.3 — Import duty, VAT, levies, fees and their tax bases

Course 3: Classification, Valuation, Origin and Duty · difficulty `intermediate`
Module 8: Customs Valuation and Duty Calculation · lesson 3 of 4 · module 8 of 15
Proposed slug: `import-duty-vat-levies-fees-and-their-tax-bases`

## Summary

A declaration settles more than one charge: import duty on the CIF, VAT on the
duty-inclusive base, and levies and fees each on their own base. Act 891 imposes the
duties and taxes (s.1), exempts what the HS exempts (s.2), and provides liability and
calculation in ss.71–72 — while the tariff workbook's VAT and IE columns carry the
per-TSN charges. This lesson teaches the charge stack and each charge's tax base.

## Learning Objectives

State the charge stack on a typical import — import duty, import VAT, processing fee, ECOWAS levy — and each one's tax base as the supplied sources present them.
Identify where each charge comes from in the Act: imposition (s.1), exemptions (s.2), liability (s.71), calculation (s.72).
Explain the "duty-inclusive base" idea: why VAT's base includes the duty.
Read the tariff workbook's VAT and IE columns for a TSN row, and the SU column's role.

## Key Terms

duty :: customs duty, excise duty, tax or other charges collectible on imported or exported goods
tariff :: the Tariff Schedule of Ghana
customs value of imported goods :: the value of goods, determined in accordance with this Act

## Source anchors

- `ACT` s.151 — the Key Terms above, verbatim from the Interpretation section.
- `ACT` s.1 — imposition (including s.1(2)(a): any other tax, duty or levy prescribed
  under another enactment — the hook the levies hang on); s.2 — exempt duties and
  taxes.
- `ACT` ss.71–72 — liability for duty and calculation of duty.
- `TARIFF` — the workbook's VAT, IE and SU columns; cite the table and row used.
- `FULL DUTY CALCULATIONS - AKYA` — the scan's tax-element table (Import Duty 1 on
  CIF; Import VAT 2 on CIF + Import Duty; Processing Fee 5; ECOWAS Levy 6 — extracted
  text, verified 2026-11-16), as the worked structure illustration.

**Fact-check caution.** Rates are structure-illustrative only (spec C4.2): the VAT
rate shown in the scan is the scan's, not a current fact. Exemption claims must cite
s.2 or the HS schedule's exemption notes; do not import external exemption lists.
