# LESSON BRIEF 8.1 — Transaction value and the hierarchy of valuation methods

Course 3: Classification, Valuation, Origin and Duty · difficulty `intermediate`
Module 8: Customs Valuation and Duty Calculation · lesson 1 of 4 · module 8 of 15
Proposed slug: `transaction-value-and-the-hierarchy-of-valuation-methods`

## Summary

Duty hangs on value, and value has a legal hierarchy: transaction value first — the
price actually paid or payable for the goods — with structured fallbacks when it
cannot be used. Act 891 names customs value and provides the method sequence in
sections 67 and 68. This lesson teaches the hierarchy's order and why the order is
itself the law.

## Learning Objectives

State what "customs value of imported goods" means under the Act and where it comes from.
Walk the valuation hierarchy: transaction value first, then the fallback methods in the order section 68 provides.
Explain why the method order is mandatory — a trader may not shop for the cheapest method.
Identify when transaction value fails: conditions the price must satisfy before it can be used.

## Key Terms

customs value of imported goods :: the value of goods, determined in accordance with this Act
duty :: customs duty, excise duty, tax or other charges collectible on imported or exported goods
identical goods :: goods, which are the same in all respects, including physical characteristics, quality, and reputation, but disregarding minor differences in appearance
similar goods :: goods which, although not alike in all respects, have like characteristics and like component materials which enable them to perform the same functions and to be commercially interchangeable

## Source anchors

- `ACT` s.151 — the Key Terms above, verbatim from the Interpretation section
  ("identical goods" and "similar goods" are the defined comparators the fallback
  methods use).
- `ACT` s.67 — customs valuation: quote the provision's method framing.
- `ACT` s.68 — where customs value cannot be determined: the fallback sequence.
- `FULL DUTY CALCULATIONS - AKYA` — a scan; only its first-page tax-element table
  yields machine text (Import Duty on CIF, Import VAT at 15% on CIF + Import Duty,
  Processing Fee 1%, ECOWAS Levy 0.5% — extracted, verified 2026-11-16). Cite the
  page if used; otherwise read visually per spec C3 and say so in `FACTS & SOURCES`.

**Fact-check caution.** Rates shown in the scan's tax table are illustrative of the
structure — the tariff-edition labelling rule (spec C4.2) applies. The method
sequence must follow the Act's own order; do not import the WTO Valuation Agreement's
numbering unless the Act uses it too.
