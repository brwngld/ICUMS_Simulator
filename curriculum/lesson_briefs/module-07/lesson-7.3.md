## Summary (from curriculum)
This lesson examines containerisation and its role in modern international cargo transportation. Learners will explore how standardised shipping containers facilitate cargo handling, storage, and multimodal transportation. The lesson explains the differences between full container load and less than container load shipments, introduces common container types and sizes, and examines the basic procedures involved in container selection, loading, securing, and movement.

## Learning Objectives (from curriculum)
Define containerisation and explain its importance in international logistics.
Identify the advantages of using standardised shipping containers.
Distinguish between full container load and less than container load shipments.
Identify common container types and their appropriate cargo applications.
Explain the differences between standard, high-cube, refrigerated, open-top, and flat-rack containers.
Describe the basic procedures involved in container loading and cargo securing.
Explain the purpose of container identification numbers and security seals.
Identify factors influencing container selection for different shipments.
Describe the role of container freight stations in consolidated cargo operations.
Recognise common operational and safety considerations associated with containerised transportation.

## Key Terms (from curriculum)
Containerisation :: The use of standardised freight containers to transport goods efficiently across different transportation modes.
Shipping Container :: A reusable transport unit designed for the secure and efficient movement of cargo.
Full Container Load (FCL) :: A container shipment generally arranged for the use of one shipper or consignee rather than being consolidated with unrelated shipments.
Less than Container Load (LCL) :: A shipment occupying part of a container and typically consolidated with cargo belonging to other shippers.
Twenty-Foot Equivalent Unit (TEU) :: A standard measurement of container capacity equivalent to one nominal 20-foot shipping container.
Forty-Foot Equivalent Unit (FEU) :: A container capacity measurement equivalent to one nominal 40-foot shipping container, generally equal to two TEUs.
Dry Container :: An enclosed container designed for transporting general cargo that does not require temperature control.
High-Cube Container :: A container with greater internal height than a corresponding standard-height container.
Refrigerated Container (Reefer) :: A temperature-controlled container used to transport goods requiring specified temperature conditions.
Open-Top Container :: A container with a removable or flexible roof covering, suitable for certain oversized or top-loaded cargo.
Flat-Rack Container :: A container platform with end structures, designed for transporting certain oversized or unusually shaped cargo.
Container Seal :: A security device used to indicate whether a container door or other secured access point has been opened or tampered with.
Container Number :: A standardised identification code assigned to a freight container.
Container Freight Station (CFS) :: A facility used for receiving, consolidating, deconsolidating, and handling containerised cargo.
Cargo Securing :: The process of restraining cargo to prevent unsafe movement or damage during transportation.
Verified Gross Mass (VGM) :: The verified total gross mass of a packed container determined in accordance with applicable SOLAS requirements.
