## Summary (from curriculum)
This lesson introduces security risks affecting international logistics networks and the measures used to protect cargo, facilities, information, and transportation systems. Learners will examine cargo theft, tampering, unauthorised access, fraud, and shipment diversion. The lesson also explores container seals, access control, cargo inspections, traceability, and the importance of secure procedures and accurate records.

## Learning Objectives (from curriculum)
Define supply chain security and cargo integrity.



Identify common security threats affecting logistics operations.



Explain how cargo theft, tampering, and fraud affect supply chain performance.



Describe the purpose of container seals and cargo security inspections.



Identify common physical security measures used in logistics facilities.



Explain the importance of access control and personnel identification.



Describe how shipment tracking and audit trails support cargo security.



Recognise the role of documentation and data security in protecting shipments.



Explain how security incidents should be reported and investigated.



Identify preventive measures that reduce cargo security risks.

## Key Terms (from curriculum)
Supply Chain Security :: The measures used to protect goods, people, facilities, information, and transport systems against security threats throughout the supply chain.

Cargo Integrity :: The assurance that goods remain complete, authentic, and protected against unauthorised interference or alteration.

Cargo Theft :: The unlawful taking of goods during transportation, handling, or storage.

Cargo Tampering :: Unauthorised interference with cargo, packaging, seals, or transport equipment.

Container Seal :: A device used to indicate whether a secured container access point has been opened or interfered with.

High-Security Seal :: A seal designed to meet specified security and mechanical requirements under an applicable standard.

Access Control :: Procedures and systems restricting entry to authorised persons or vehicles.

Chain of Custody :: A documented record of the possession, control, handling, or transfer of goods or evidence.

Shipment Traceability :: The ability to reconstruct a shipment's history, movement, and relevant handling events.

Security Inspection :: An examination performed to identify potential security threats, tampering, or unauthorised items.

Cargo Diversion :: The unauthorised or fraudulent redirection of goods from their intended movement or destination.

Audit Trail :: A chronological record enabling transactions, movements, or changes to be traced.

Security Incident :: An event that threatens or compromises the safety, integrity, or security of logistics operations.
