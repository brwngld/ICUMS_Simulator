## Summary (from curriculum)
This lesson introduces transportation management systems and warehouse management systems as important technologies used in modern logistics. Learners will examine how these systems support shipment planning, carrier selection, warehouse operations, inventory tracking, order processing, and performance monitoring. The lesson also explains how system integration improves information accuracy and operational coordination.

## Learning Objectives (from curriculum)
Define transportation management systems and warehouse management systems.



Explain the principal functions of a transportation management system.



Describe how warehouse management systems support daily warehouse operations.



Distinguish between transportation management, warehouse management, and enterprise resource planning systems.



Identify common data recorded and processed by logistics management systems.



Explain how digital systems support shipment and inventory visibility.



Describe the benefits of integrating logistics systems with other business applications.



Recognise common challenges associated with system implementation and adoption.



Explain the importance of data accuracy, access control, and user training.



Evaluate basic system requirements for a logistics organisation.

## Key Terms (from curriculum)
Transportation Management System (TMS) :: Software used to plan, execute, monitor, and optimise transportation activities.

Warehouse Management System (WMS) :: Software used to manage and control warehouse operations, inventory locations, and stock movements.

Enterprise Resource Planning (ERP) :: An integrated software system used to manage major organisational processes and business information.

Order Management System (OMS) :: Software used to receive, process, track, and manage customer orders.

System Integration :: The process of connecting software applications so they can exchange data and support coordinated operations.

Inventory Visibility :: The ability to access timely information about inventory quantities, locations, and status.

Barcode :: A machine-readable representation of information used to identify and track items.

Radio Frequency Identification (RFID) :: A technology that uses radio signals to identify and exchange information with tagged objects.

Application Programming Interface (API) :: A defined interface that enables software applications to exchange information or invoke supported functions.

Real-Time Data :: Information made available with sufficiently low delay to support immediate or near-immediate operational decisions.

Access Control :: Mechanisms used to restrict system functions and information to authorised users.

System Implementation :: The process of configuring, deploying, testing, and introducing a software system into operational use.
